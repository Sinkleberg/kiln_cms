## 1.6 — "What readers saw" (#1928) · demo line 4

Number: none new; makes 1.5's number visible. PRs in order:

1. **#2019 vector-scan crash-loop.** A boot crash, so it goes first. The fix
   is in the issue: each env var writes a complete mode (`ef_search: nil,
   exact: true` / `ef_search: n, exact: false`). Downstream has a workaround
   (don't set `KILN_VECTOR_SEARCH_EXACT`), so it waits for 1.6 rather than a
   v1.5.1. Cut a patch only if Verscienta asks.
2. **Timeline rows in the governance detail view.** One row per transition:
   approver, propagation record (purge time, each endpoint's delivery time,
   terminal failure), `?as_of=` link, chain verdict. Load the propagation
   records in one query per document, not one per row.
3. **Export columns.** The JSON and CSV trail exports carry the same columns.
   Additive: new columns go on the end of the CSV.
4. **#1887 headless draft mode.** The largest and riskiest piece: a preview
   token becomes a read grant for exactly one record on the plain reads.
   Its own PR, with a `/security-review` pass before merge. The issue's
   design stands: a FilterCheck on the primary `:read` only, no
   `authorize?: false`, the token in `Vary`, `filter_parameters`, its own rate
   bucket, `private, no-store`.
5. **Production-site riders** (allowed under the freeze, since Verscienta asks):
   - **#1862** `id` and `slug` on `/api/ask` sources. Small and additive.
   - **#1863** plugin editor notices. Verscienta's K2 banner waits on it. The
     issue already carries a full design and test list.
6. **Governance guide screenshot** of one real correction traced end to end.
   Needs staging. **Take the #1927 measurement in the same staging session**,
   so the 2.0 benchmark row isn't left until the end.

## 1.7 — Provenance on by default (#1929) · demo line 4

Number: share of published artifacts signed. PRs in order:

1. **Unsigned path first:** existing installs without a key serve `unsigned`,
   a console banner names the one env var, and nothing is refused. Shipping
   this before the default flips means no upgrade can break.
2. **`/setup` generates a signing key** and turns provenance on for new
   installs.
3. **`GET /api/provenance/verify/:type/:slug`**: `verified` / `tampered` /
   `unsigned`, anonymous, cacheable, added to the covered surface.
4. **The metric:** signed share as telemetry and on benchmarks.md.
5. **Upgrade note**, rehearsed by the upgrade workflow.
6. **API riders** (small and additive; they make 1.8's "try it" examples work):
   - **#1884** a missing `?locale=` on by-slug resolves to the site default
     through the fallback chain, so a 400 becomes a 200. Check GraphQL
     `pageBySlug` and the delivery API for the same behaviour.
   - **#1885** an exact-match `GET /api` 302 to `/developers`.
